# Memorial Lotes Pro — Site Comercial

Pacote completo e pronto para publicação no GitHub Pages.

## Como publicar

1. Abra o repositório do site no GitHub.
2. Apague ou substitua os arquivos antigos.
3. Envie **todo o conteúdo desta pasta**, mantendo as pastas `css`, `js` e `img`.
4. Confirme que o arquivo `CNAME` está na raiz.
5. Aguarde a publicação do GitHub Pages.

## Estrutura

- `index.html`: página principal completa.
- `css/style.css`: todos os estilos do site.
- `js/script.js`: menu, abas de recursos, animações e galeria.
- `img/`: logotipo e imagens reais do plugin.
- `politica-de-privacidade.html`: política de privacidade.
- `termos-de-uso.html`: termos institucionais do site.
- `404.html`: página de erro personalizada.
- `robots.txt` e `sitemap.xml`: arquivos de indexação.
- `CNAME`: domínio `memoriallotespro.com.br`.

## Observação importante

Não existe chave de licença salva no JavaScript do site. A licença do plugin deve ser validada pelo próprio aplicativo ou por um serviço seguro no servidor, nunca por uma lista de chaves exposta no navegador.
